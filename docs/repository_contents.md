## Files and folders intentionally ignored

The following are local/generated files and should not be uploaded:

```text
outputs/
presentations/
simulation_outputs/
ALRD.Rcheck/
*.tar.gz
.Rhistory
.RData
.DS_Store
simulation_report.html
simulation_report.md
```

Why:

- `outputs/` and `presentations/` contain generated meeting materials.
- `simulation_outputs/` contains generated simulation results.
- `ALRD.Rcheck/` and `*.tar.gz` are generated by R package checks.
- `.Rhistory`, `.RData`, and `.DS_Store` are local machine files.

## Recommended GitHub Desktop workflow

1. Open GitHub Desktop.
2. Choose **File > Add Local Repository**.
3. Select:

```text
/Users/zhikuan_quan/Documents/GitHub/ALRD
```

4. Confirm the current branch is `main`.
5. Publish the repository to GitHub.
6. Choose `Private` until the package is ready to share publicly.
7. After publishing, invite collaborators from the GitHub website.

## Repository visibility recommendation

Use a private GitHub repository during active method development. Switch to
public only after:

- package API is stable;
- documentation is complete;
- collaborators agree on release scope;
- simulation evidence is ready to share.
