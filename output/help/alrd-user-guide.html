ALRD: A practical guide to longitudinal treatment-effect estimation

Purpose and installation

ALRD estimates a treated-minus-control conditional mean contrast from continuous repeated outcomes. LRD directly models the contrast; ALRD first models a main effect and then fits the residualized response. Positive ITE favors treatment only when larger outcomes are preferred. The intended design has independent subjects and one baseline treatment per subject. This development version does not implement treatment switching, survival outcomes, or inferential intervals.

With signed baseline treatment Ti∈{−1,1}T_i \in \{-1,1\}, the outcome model is

Yij=m(Xij)+Ti2δ(Xij)+εij. Y_{ij} = m(X_{ij}) + \frac{T_i}{2}\delta(X_{ij}) + \varepsilon_{ij}.

Here m(Xij)m(X_{ij}) is the main effect, δ(Xij)\delta(X_{ij}) is the full treated-minus-control contrast, and εij\varepsilon_{ij} is the outcome error.

Install the package and dependencies:

install.packages("ALRD")
install.packages("glmnet")

The lasso option requires glmnet. This is not a claim of CRAN availability. Use help(package = "ALRD"), ?fit_alrd, and the other function help pages.

Treatment is assigned once per subject in this simulator. Numeric -1/1 or 0/1 coding is recommended. For factor treatment the second level is treated; for character treatment the alphabetically second value is treated.

List existing columns in covariates; an intercept is added automatically. Precompute interactions such as time_z1 = time * z1. Both ALRD stages share the same basis. This compact example omits other prognostic variables in the simulator. The simulator’s correlated option concerns baseline covariates; outcome errors always include a random intercept with conditional correlation 0.5.

Hold out subjects before fitting

set.seed(7)
training_ids <- sample(unique(dat$id), 75)
train <- dat[dat$id %in% training_ids, ]
test <- dat[!dat$id %in% training_ids, ]
stopifnot(length(intersect(train$id, test$id)) == 0L)

Keep all visits from each subject together. Fit nuisance models and tune models using only training subjects. Reserve the test sample for evaluation.

Supply the known treatment probability explicitly for randomized studies. With ps = NULL, LRD assumes 0.5, whereas ALRD estimates a logistic model from all long-data rows using the outcome covariates.

The coefficients describe the ITE basis. However, fitted.values is the treatment contribution Tiδ̂(Xij)/2T_i\widehat{\delta}(X_{ij})/2, not the ITE or full outcome. For ALRD, the full fitted outcome also includes main_effect. Obtain contrasts using predict_ite().

Matrices have unit diagonal and ascending time order within each subject. AR(1) uses actual numeric time differences, not visit positions. For visits jj and kk of subject ii, its entries are

(Vi)jk=ρ|tij−tik|. (V_i)_{jk} = \rho^{|t_{ij}-t_{ik}|}.

Omitting rho triggers estimation for non-independence models. Supplied rho is fixed by default; estimate_rho = TRUE instead uses it as a starting value. Inspect converged: reaching the iteration limit does not issue a warning.

Both stages use lasso and select their own lambda.min. Only the ITE stage is refitted without penalty. lambda_1se is stored but not used for selection. Selected terms are design columns, including possibly the intercept and factor contrasts, not necessarily distinct clinical variables.

Subject folds keep repeated rows together inside each glmnet call. However, main-effect residualization, internally estimated propensity scores, and working correlation use the full fitting sample before ITE-stage validation. Consequently, this CV curve does not validate the entire procedure. Use external test subjects and plan full-pipeline subject resampling before publication.

Predictions and evaluation

prediction <- predict_ite(alrd, test)
stopifnot(length(prediction) == nrow(test), all(is.finite(prediction)))
subject_mse <- tapply((prediction - test$true_ite)^2, test$id, mean)
subject_agreement <- tapply((prediction > 0) == (test$true_ite > 0), test$id, mean)
data.frame(metric = c("Mean subject trajectory MSE", "Mean subject sign agreement"),
            value = c(mean(subject_mse), mean(subject_agreement)))
#>                        metric    value
#> 1 Mean subject trajectory MSE 9.986187
#> 2 Mean subject sign agreement 0.792000

These explicitly defined demonstration metrics do not replace the definitions in the existing simulation scripts. True ITE is known only in simulation. This single split is a usage example, not evidence of superiority or validated subgroup effects. Real-data evaluation requires an appropriate observable policy-value or subgroup-effect estimator.

Predict one fixed covariate profile over time, recomputing all interactions:

profile <- test[rep(1, 5), covs, drop = FALSE]
profile$time <- 1:5
for (nm in c("z1", "z2", "z11", "z12")) {
  profile[[paste0("time_", nm)]] <- profile$time * profile[[nm]]
}
trajectory <- predict_ite(alrd, profile)
plot(profile$time, trajectory, type = "b", xlab = "Time",
     ylab = "Estimated treated-minus-control contrast")
abline(h = 0, lty = 2, col = "grey50")

A time-dependent contrast under baseline treatment does not establish that switching treatment at a particular visit would improve outcomes.

Observational baseline assignment

Fit the propensity model on one row per subject with pre-treatment confounders and map scores to visits. For an external evaluation, fit this model on training subjects only and predict for held-out subjects.

obs <- simulate_alrd_data(n = 100, scenario = 3, seed = 15)
baseline <- obs[!duplicated(obs$id), ]
ps_fit <- estimate_ps(baseline, treatment, c("z1", "z2", "z11", "z12"))
ps_rows <- ps_fit$scores[match(obs$id, baseline$id)]
stopifnot(length(ps_rows) == nrow(obs), all(ps_rows > 0 & ps_rows < 1))
tapply(ps_fit$scores, baseline$treatment, range)
#> $`-1`
#> [1] 0.07635625 0.92098474
#> 
#> $`1`
#> [1] 0.2586560 0.9673418
obs_fit <- fit_alrd(obs, id, time, treatment, outcome, covs, ps = ps_rows,
                    covariance = "exchangeable", rho = 0.5)
head(predict_ite(obs_fit))
#> [1] -2.297498 -3.791679 -5.285860 -6.780041 -8.274222  2.565249

This last example demonstrates fitting only. Clipping does not establish overlap; inspect unclipped probabilities and covariate balance before analysis. Do not include post-treatment variables in a baseline assignment model.

Data dictionary and function selection

Use one row per subject and visit. Column names are configurable in fitting calls; the names below are those used by the running example.

Field Meaning Requirement
id Independent subject identifier Nonmissing; repeats across that subject’s visits.
time Measurement time Finite numeric values; distinct within subject for AR(1). Units determine rho interpretation.
treatment Baseline treatment arm Constant within subject; prefer numeric -1/1 or 0/1.
outcome Observed repeated response Complete, finite, continuous numeric values.
Covariate columns Prognostic/moderator basis Complete values; construct interactions before fitting.
Supplied ps Probability of the treated arm Scalar or one value per data row; strictly between 0 and 1.
Supplied weights Additional analysis weights Use positive values constant within subject for the documented loss.

The simulator’s true_main, true_ite, and propensity are known generating quantities. Do not use truth columns as predictors in a performance comparison. Numeric covariate columns are the most reliable current prediction interface; factor encoding needs particular care as described in ?predict_ite.

Goal Function Main result
Create a reproducible example simulate_alrd_data() Long-format data with known generating quantities.
Estimate baseline assignment estimate_ps() Logistic model and clipped treated-arm scores.
Inspect within-subject correlation working_covariance() Named list of correlation matrices.
Fit direct learning without augmentation fit_lrd() Unpenalized lrd_fit object.
Fit augmented learning, optionally sparse fit_alrd() alrd_fit with both stage results.
Obtain contrasts for a new covariate profile predict_ite() Numeric treated-minus-control contrasts.

Fitted-object reference

Both fitting functions accept bare column names or strings for the data-role arguments. For programmatic calls, strings make the mapping explicit. covariates is always a character vector of existing column names.

Component Interpretation
coefficients ITE coefficients; names have an ite_ prefix. ALRD lasso coefficients may be post-selection refitted.
fitted.values Treatment contribution Tiδ̂(Xij)/2T_i\widehat{\delta}(X_{ij})/2, not the full ITE.
residuals Outcome minus the fitted contribution; ALRD also subtracts the main effect.
main_effect, main_model ALRD-only first-stage predictions and fitted model.
propensity_scores Probabilities of the treated arm in input-row order.
propensity_for_received Treated probability for treated subjects, its complement for controls.
rho_estimation List with estimated, history, converged, iterations, and tolerance.
selected_terms ALRD’s ITE design-column names; all columns for unpenalized fits.
lambda, lambda_1se Lasso-only tuning summaries. The fit uses lambda.min.
lasso_coefficients, refit_model Lasso-only penalized coefficients and optional unpenalized refit.
cv_model Lasso-only ITE-stage cv.glmnet object; first-stage tuning is in main_model.

print(fit) reports the fit configuration. There are currently no dedicated summary(), confint(), or model plot() methods; use documented components and predict_ite() rather than interpreting a generic list summary as inference.

Current limitations

Issue Action for this version
Missing fitting values Fitting rejects them; justify a missing-data strategy first.
Missing prediction values Rows may be silently dropped; check completeness and output length.
Reordered or novel factor levels Use a consistently prepared numeric basis until factor encoding is fixed.
Collinear columns NA coefficients may propagate to all predictions; check model-matrix rank.
Zero weights Residual length can disagree with metadata; avoid until fixed.
Within-subject varying weights Their loss differs from scalar subject weighting; use positive subject-constant weights.
Invalid covariance Out-of-range exchangeable rho and duplicate AR(1) times are now rejected explicitly.
Fractional times Use nonnegative rho for AR(1); negative rho with fractional gaps is rejected.
Two folds Use at least three subjects and three folds.
Inference Dedicated standard errors, intervals, and subgroup validation are absent.

For troubleshooting retain the call, data dimensions, treatment coding, propensity range, visit times, and convergence history.
