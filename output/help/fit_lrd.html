fit_lrd {ALRD}R Documentation

Fit longitudinal residual difference learning

Description

Estimate a continuous longitudinal treatment contrast by inverse-propensity weighted generalized least squares without a main-effect augmentation stage.

Usage

fit_lrd(
  data,
  id,
  time,
  treatment,
  outcome,
  covariates = NULL,
  ps = NULL,
  covariance = c("independence", "exchangeable", "ar1"),
  rho = NULL,
  estimate_rho = NULL,
  rho_max_iter = 5L,
  rho_tol = 0.001,
  weights = NULL
)

Arguments

data

Data frame with one row per subject and visit. Use complete, finite outcomes and covariates, unique subject-time pairs, and a baseline treatment that is constant within subject. These requirements are not all enforced by the current implementation.

id

Subject identifier, as a bare column name or a single string.

time

Numeric measurement-time column, as a bare name or string. For AR(1), the numeric time difference determines the correlation.

treatment

Binary treatment column, as a bare name or string. Numeric -1/1 or 0/1 and logical values are accepted. For factors the second level is treated; for character values the alphabetically second value is treated. Explicit numeric coding is recommended.

outcome

Continuous numeric outcome column, as a bare name or string.

covariates

Character vector of existing covariate column names. NULL fits an intercept-only treatment contrast. An intercept is always added.

ps

Treated-arm probability, as a scalar or one probability per input row, strictly between zero and one. NULL uses 0.5 for every row, unlike fit_alrd(), which estimates scores when ps is NULL.

covariance

"independence" (default), "exchangeable", or "ar1". See working_covariance() for mathematical definitions and restrictions.

rho

Optional correlation parameter. Supplying rho fixes it by default; with estimate_rho = TRUE it is instead the starting value. If omitted, the initial value is zero for independence and 0.3 otherwise.

estimate_rho

Logical. Default: update rho only when rho is omitted and covariance is not independence. Independence always disables updating.

rho_max_iter

Maximum number of correlation updates, default five.

rho_tol

Positive tolerance for the absolute change in rho.

weights

Optional numeric vector in input-row order, multiplied by inverse received-treatment probabilities. Although zeros and within-subject variation are accepted, their handling has unresolved limitations; use strictly positive weights constant within subject for the documented loss.

Details

The design is T_i B_i/2, with signed treatment T_i \in \{-1,1\} and subject-specific basis matrix B_i. For weights constant within subject, the criterion is

\sum_{i=1}^{n} w_i \left(\mathbf{Y}_i - \frac{T_i}{2}B_i\beta\right)^{\mathsf{T}} V_i^{-1} \left(\mathbf{Y}_i - \frac{T_i}{2}B_i\beta\right).

Here w_i = a_i/\pi_{T_i}(Z_i) combines the optional analysis weight a_i (one by default) and the inverse probability of the treatment received; V_i is the working correlation. There is no penalized LRD option in this release. Treatment coding, covariance restrictions, weight limitations, and prediction limitations are described in fit_alrd() and working_covariance().

For a baseline observational treatment, estimate propensity scores on one row per subject using baseline confounders, then map the scores to all visits. Automatic validation of constant within-subject treatment is not implemented.

Value

An lrd_fit list containing coefficients (with ite_ prefixes), fitted.values (T_i\widehat{\delta}(X_{ij})/2), residuals (Y minus fitted.values), rank, df.residual, covariance, rho, propensity_scores, propensity_for_received, and rho_estimation. The latter contains estimated, history, converged, iterations, and tolerance. Training metadata are stored in model_frame, basis_formula, basis_terms, id, time, treatment, outcome, and covariates. No standard errors or confidence intervals are computed.

See Also

fit_alrd(), predict_ite(), working_covariance()

Examples

dat <- simulate_alrd_data(n = 60, seed = 8)
fit <- fit_lrd(dat, "id", "time", "treatment", "outcome",
               covariates = c("time", "z1", "time_z1"), ps = 0.5)
print(fit)
head(predict_ite(fit, dat))
constant <- fit_lrd(dat, id, time, treatment, outcome, ps = 0.5)
constant$coefficients
