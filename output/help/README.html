This is a development prototype. Read the code review and collaborator tasks for current prediction, covariance, weighting, and validation limitations before using it for a substantive analysis.

ALRD implements the longitudinal robust direct learning methods from Doubly Robust Estimation of Individualized Treatment Effects in Longitudinal Data. The package directly estimates time-specific individualized treatment effects (ITEs) from repeated outcome measurements while accounting for within-subject correlation.

The paper writes treatment as Ti=1T_i = 1 for treatment and Ti=−1T_i = -1 for control and uses the decomposition

Yij=m(Xij)+Ti2δ(Xij)+εij. Y_{ij} = m(X_{ij}) + \frac{T_i}{2}\delta(X_{ij}) + \varepsilon_{ij}.

This package accepts treatment coded as either -1/1 or 0/1; internally the learning objective is fit on the -1/1 scale.

Algorithms

fit_lrd() fits LRD-Learning by minimizing the inverse-propensity weighted longitudinal loss

∑i=1n1πTi(Zi){𝐘i−Ti2𝐟(𝐗i)}𝖳Vi−1{𝐘i−Ti2𝐟(𝐗i)}. \sum_{i=1}^{n} \frac{1}{\pi_{T_i}(Z_i)} \left\{\mathbf{Y}_i - \frac{T_i}{2}\mathbf{f}(\mathbf{X}_i)\right\}^{\mathsf{T}} V_i^{-1} \left\{\mathbf{Y}_i - \frac{T_i}{2}\mathbf{f}(\mathbf{X}_i)\right\}.

Here πTi(Zi)\pi_{T_i}(Z_i) is the probability of the treatment received, ViV_i is the working correlation matrix, and bold symbols collect a subject’s repeated measurements.

fit_alrd() fits ALRD-Learning with the paper’s two-stage augmentation:

  1. Estimate the main effect m(X)m(X) from the weighted working covariance loss.
  2. Estimate the ITE from the augmented outcome Yij−m̂(Xij)Y_{ij} - \widehat{m}(X_{ij}) using Tif(Xij)/2T_i f(X_{ij})/2.

For fit_alrd(), use penalty = "none" for the non-penalized version and penalty = "lasso" for lasso variable selection. The lasso version uses clustered cross-validation, so all repeated measurements from the same subject stay in the same fold. By default, it refits the selected ITE terms without penalty to reduce shrinkage bias, matching the real-data analysis strategy in the paper.

For exchangeable and AR(1) working covariance structures, rho is estimated iteratively when it is omitted. The fitting functions repeat: fit the model, estimate rho from residuals, and refit until convergence. To fix the working correlation instead, pass rho directly, for example rho = 0.5.

Key lasso outputs include:

fit$lambda              # selected lambda
fit$lambda_1se          # one-SE lambda
fit$lasso_coefficients  # penalized ITE coefficients
fit$coefficients        # final coefficients, refit if refit = TRUE
fit$selected_terms      # selected ITE design terms
fit$selected_covariates # selected treatment-effect covariates
fit$main_model          # first-stage main-effect fit

Toy Simulation Example

simulate_alrd_data() follows the paper’s simulation structure: five repeated measurements, baseline continuous and binary covariates, a random subject intercept inducing exchangeable correlation, and scenarios with correct or misspecified main-effect and propensity-score models.

library(ALRD)

dat <- simulate_alrd_data(
  n = 120,
  scenario = 1,
  main_effect_size = "large",
  correlated = TRUE,
  seed = 1
)

ite_covariates <- c(
  "time",
  paste0("z", 1:20),
  paste0("time_z", 1:20)
)

Non-Penalized ALRD

fit_np <- fit_alrd(
  data = dat,
  id = "id",
  time = "time",
  treatment = "treatment",
  outcome = "outcome",
  covariates = ite_covariates,
  ps = 0.5,
  penalty = "none",
  covariance = "exchangeable"
)

head(predict_ite(fit_np, dat))

Lasso ALRD With Unpenalized Refit

fit_lasso <- fit_alrd(
  data = dat,
  id = "id",
  time = "time",
  treatment = "treatment",
  outcome = "outcome",
  covariates = ite_covariates,
  ps = 0.5,
  penalty = "lasso",
  refit = TRUE,
  nfolds = 5,
  seed = 10,
  covariance = "exchangeable"
)

fit_lasso$lambda
fit_lasso$selected_covariates
head(predict_ite(fit_lasso, dat))

Evaluating ITE Recovery

The simulation data include the true time-specific ITE, so a quick check can compare the predicted ITE with the truth.

pred <- predict_ite(fit_lasso, dat)
cor(pred, dat$true_ite, method = "spearman")
mean(abs(pred - dat$true_ite))
