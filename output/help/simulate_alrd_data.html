simulate_alrd_data {ALRD}R Documentation

Simulate continuous longitudinal treatment-effect data

Description

Generate repeated continuous outcomes with baseline binary treatment, known propensity scores, main effects, and treatment contrasts. This is a simulation helper; correspondence with the underlying method paper must be verified separately before claiming exact replication.

Usage

simulate_alrd_data(
  n = 200,
  times = 1:5,
  scenario = 1L,
  main_effect_size = c("large", "small"),
  correlated = TRUE,
  seed = NULL
)

Arguments

n

Positive integer number of independent subjects, default 200.

times

Nonempty numeric vector of distinct, finite visit times, default 1:5. All subjects use the same schedule.

scenario

Integer 1 through 5. See the scenario definitions below.

main_effect_size

"large" (default) or "small"; scales the coefficients entering the main effect before any squaring.

correlated

Logical; whether baseline covariates arise from correlated latent normal variables. This does not control outcome error correlation.

seed

Optional seed passed to set.seed(). This changes the caller's global random-number state.

Details

Outcomes follow Y = true_main + treatment * true_ite / 2 + subject_random_intercept + independent_error. The random intercept and error each have variance one, giving conditional exchangeable outcome error correlation 0.5 in every scenario, even with correlated = FALSE.

There are ten continuous and ten binary baseline covariates. When correlated is TRUE, the underlying 20-dimensional normal vector has correlation 0.5^abs(j-k); binary covariates are obtained by thresholding at zero. The observed binary correlations need not equal the latent correlations.

Scenarios 1 and 2 have randomized treatment probability 0.5, with a linear main effect in scenario 1 and a squared main effect in scenario 2. Scenarios 3 and 4 use logistic assignment with predictor z1 - z2 + z11 - z12, and respectively linear and squared main effects. Scenario 5 uses randomized treatment, a squared main effect, and nonlinear ITE terms z + 5z^2 for z1, z2, z11, and z12, with signs +, -, +, -. For scenarios 1–4 these moderators enter as z + timez. Each ITE also has intercept 0.5 and time slope 0.3.

These are properties of the data-generating mechanism, not automatic labels of fitted-model correctness; correctness depends on the fitted basis. In particular, squared binary covariates equal the original binary covariates.

Value

Data frame with n * length(times) rows sorted by id and time: id, time, treatment (-1/1), outcome, true_main, true_ite, propensity, z1 through z20, and time_z1 through time_z20. The propensity column, not a column named ps, contains the known treated-arm probability.

See Also

fit_alrd(), fit_lrd(), estimate_ps()

Examples

dat <- simulate_alrd_data(n = 40, scenario = 3, seed = 9)
head(dat[, c("id", "time", "treatment", "outcome", "true_ite", "propensity")])
fit <- fit_lrd(dat, id, time, treatment, outcome,
               covariates = c("time", "z1", "z2"),
               ps = dat$propensity)
head(predict_ite(fit))
