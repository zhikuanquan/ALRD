fit_alrd {ALRD}R Documentation

Fit augmented longitudinal residual difference learning

Description

Estimate a continuous longitudinal treatment contrast in two stages: fit a main-effect model, then regress the residualized outcome on the signed treatment multiplied by a covariate basis divided by two.

Usage

fit_alrd(
  data,
  id,
  time,
  treatment,
  outcome,
  covariates,
  ps = NULL,
  penalty = c("none", "lasso"),
  refit = TRUE,
  nfolds = 5L,
  lambda = NULL,
  seed = NULL,
  standardize = TRUE,
  covariance = c("independence", "exchangeable", "ar1"),
  rho = NULL,
  estimate_rho = NULL,
  rho_max_iter = 5L,
  rho_tol = 0.001,
  weights = NULL
)

Arguments

data

Data frame with one row per subject and visit. Use complete, finite outcomes and covariates, unique subject-time pairs, and a baseline treatment that is constant within subject. These requirements are not all enforced by the current implementation.

id

Subject identifier, as a bare column name or a single string.

time

Numeric measurement-time column, as a bare name or string. For AR(1), the numeric time difference determines the correlation.

treatment

Binary treatment column, as a bare name or string. Numeric -1/1 or 0/1 and logical values are accepted. For factors the second level is treated; for character values the alphabetically second value is treated. Explicit numeric coding is recommended.

outcome

Continuous numeric outcome column, as a bare name or string.

covariates

Character vector of existing column names, with at least one entry. An intercept is added. The same basis is used for both stages. Construct interactions or nonlinear basis columns before fitting.

ps

Probability of the treated arm, either a scalar or a numeric vector in input-row order, strictly between zero and one. For baseline assignment repeat the subject-level probability across visits. NULL estimates scores from all rows and all covariates via estimate_ps(). For a randomized study supply its known assignment probability explicitly.

penalty

"none" (default) or "lasso". Lasso is applied to both stages and requires the suggested package glmnet.

refit

Logical; for lasso, refit selected ITE columns without penalty. The main-effect stage is not refitted. Ignored for unpenalized fitting.

nfolds

Requested number of subject-level folds; default five. Use at least three subjects and three folds. The implementation caps the number at the observed subject count; two folds fail in cv.glmnet().

lambda

Optional lambda sequence passed separately to each stage's cv.glmnet() call. Each stage selects its own lambda.min; this is not a fixed-lambda argument.

seed

Optional seed for subject-fold assignment. The fold helper restores the caller's random-number state.

standardize

Logical passed to glmnet for the transformed design. Defaults to TRUE. Ignored for unpenalized fitting.

covariance

"independence" (default), "exchangeable", or "ar1". See working_covariance() for mathematical definitions and restrictions.

rho

Optional correlation parameter. Supplying rho fixes it by default; with estimate_rho = TRUE it is instead the starting value. If omitted, the initial value is zero for independence and 0.3 otherwise.

estimate_rho

Logical. Default: update rho only when rho is omitted and covariance is not independence. Independence always disables updating.

rho_max_iter

Maximum number of correlation updates, default five.

rho_tol

Positive tolerance for the absolute change in rho.

weights

Optional numeric vector in input-row order, multiplied by inverse received-treatment probabilities. Although zeros and within-subject variation are accepted, their handling has unresolved limitations; use strictly positive weights constant within subject for the documented loss.

Details

With signed treatment T_i \in \{-1,1\}, the model is

Y_{ij} = m(X_{ij}) + \frac{T_i}{2}\delta(X_{ij}) + \varepsilon_{ij}.

Here \delta(X_{ij}) is the treated-minus-control contrast. Both stages use an intercept-containing model matrix. A subject block is whitened with C = chol(solve(V)), so C^{\mathsf{T}}C = V^{-1}; square-root row weights are applied after whitening. The scalar subject-weighted loss is recovered when weights are constant within subject. Arbitrary row weights instead give a quadratic form C^{\mathsf{T}} W C and require a separate statistical specification.

Lasso leaves basis columns whose names contain "Intercept" unpenalized and selects lambda.min. The saved lambda_1se is informational, not the selected tuning rule. Selected terms refer to design columns, which may include an intercept or individual factor contrasts.

Value

An alrd_fit list. Important components are:

coefficients

Named ITE-basis coefficients, with an ite_ prefix; after refitting if requested.

fitted.values

Fitted treatment contribution T_i\widehat{\delta}(X_{ij})/2 to the residualized response, not the full fitted outcome or the ITE itself.

residuals

Outcome minus main effect and treatment contribution.

main_model, main_effect

First-stage fit and predictions.

ps_model

Result of estimate_ps(), or NULL for supplied scores.

propensity_scores, propensity_for_received

Treated-arm scores and received-arm probabilities.

rho, covariance, rho_estimation

Working correlation and structure; estimation flag, history, convergence, iterations, and tolerance.

selected_terms, selected_covariates

Selected design-column names, with or without the ite_ prefix. All columns for unpenalized fitting.

lambda, lambda_1se, cv_model

Lasso-only tuning results for the ITE stage. Main-stage results are in main_model.

lasso_coefficients, refit_model, refit

Lasso-only penalized coefficients, optional refit, and refit flag.

model_frame, basis_terms, basis_formula

Training data and basis information used for prediction.

Validation limits

Subject-fold assignment keeps repeated observations together within each cv.glmnet() call. However, main-effect residualization, any internally estimated propensities, and working correlation use the full fitting sample before ITE-stage validation. This is not full-pipeline out-of-sample validation. Use a separate subject-level test sample for performance assessment. There are no dedicated interval or subgroup-validation methods.

Zero observation weights can shorten residual vectors without updating stored row metadata. Rank deficiency can yield NA coefficients. Factor levels and contrasts are not fully preserved for new-data prediction. Inspect rho_estimation$converged: nonconvergence does not issue a warning.

See Also

fit_lrd(), predict_ite(), estimate_ps(), working_covariance()

Examples

dat <- simulate_alrd_data(n = 60, seed = 4)
covs <- c("time", "z1", "z2", "time_z1", "time_z2")
fit <- fit_alrd(dat, id, time, treatment, outcome, covs,
                ps = 0.5, covariance = "exchangeable", rho = 0.5)
print(fit)
head(predict_ite(fit))
fit$rho_estimation
if (requireNamespace("glmnet", quietly = TRUE)) {
  sparse <- fit_alrd(dat, id, time, treatment, outcome, covs,
                    ps = 0.5, penalty = "lasso", nfolds = 3, seed = 4)
  sparse$selected_terms
}
