print.alrd_fit {ALRD}R Documentation

Print a longitudinal treatment-effect fit

Description

Display the working covariance, correlation parameter, convergence status when estimated, and coefficient count. ALRD also displays the penalty and, for lasso, the selected lambda and selected-term count.

Usage

## S3 method for class 'alrd_fit'
print(x, ...)

## S3 method for class 'lrd_fit'
print(x, ...)

Arguments

x

An object returned by fit_alrd() or fit_lrd().

...

Reserved for future extensions; currently unused.

Details

This is a compact fit description, not an inferential summary. It does not report confidence intervals or validate treatment subgroups.

Value

The fitted object, invisibly.
