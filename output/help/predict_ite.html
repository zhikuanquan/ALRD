predict_ite {ALRD}R Documentation

Predict individualized treatment-effect contrasts

Description

Evaluate the fitted ITE basis for an LRD or ALRD object. This S3 generic returns a treated-minus-control mean contrast, not a potential outcome, treatment probability, or confidence interval.

Usage

predict_ite(object, newdata = NULL, ...)

Arguments

object

Object returned by fit_lrd() or fit_alrd().

newdata

Data frame with every covariate used for fitting. NULL uses the stored training data. Treatment, outcome, id and time are not required unless included among covariates.

...

Reserved for future extensions; currently unused.

Details

Prediction computes B(X) * beta. Positive values favor the treated arm only when larger outcomes are preferred. Negative values favor the control arm under that same convention. For baseline treatment, a sign that varies across visits does not define a validated treatment-switching policy.

Supply the same precomputed basis columns as in training. Missing covariate columns cause an error. Missing values may cause model.matrix() to drop rows silently, so check complete.cases() and output length. Factor levels and contrasts are not fully retained by fitted objects: preserve their training encoding, or use explicitly prepared numeric dummy columns with a fixed basis. Novel or reordered factor levels are not reliably handled.

Value

Numeric vector of ITE estimates in newdata order for complete numeric bases. With NULL, uses training-row order. Missing values and incompatible factor encoding can violate length or finiteness; see Details.

See Also

fit_alrd(), fit_lrd()

Examples

dat <- simulate_alrd_data(n = 60, seed = 6)
fit <- fit_alrd(dat, id, time, treatment, outcome,
                covariates = c("time", "z1", "time_z1"), ps = 0.5)
grid <- data.frame(time = 1:5, z1 = 0.5)
grid$time_z1 <- grid$time * grid$z1
grid$estimated_ite <- predict_ite(fit, grid)
grid
